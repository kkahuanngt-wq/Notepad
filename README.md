# 📝 Flutter Notepad CRUD App

A clean, responsive, and fully functional Notepad application built with **Flutter**. This project demonstrates how to perform **Create, Read, Update, and Delete (CRUD)** operations by consuming a RESTful API.

![Flutter](https://img.shields.io/badge/Flutter-02569B?style=for-the-badge&logo=flutter&logoColor=white)
![Dart](https://img.shields.io/badge/Dart-0175C2?style=for-the-badge&logo=dart&logoColor=white)
![REST API](https://img.shields.io/badge/REST_API-000000?style=for-the-badge&logo=postman&logoColor=white)

---

## ✨ Features

- **Create:** Add new notes with a title and content.
- **Read:** Fetch and display a list of all notes from the server.
- **Update:** Edit existing notes with a dynamic form that switches between "Create" and "Update" modes.
- **Delete:** Remove notes with a confirmation dialog to prevent accidental deletions.
- **UX/UI Enhancements:** 
  - Loading spinners while fetching data.
  - Error handling with visual SnackBar alerts.
  - Clean Material Design 3 interface.

---

## 🛠️ Tech Stack

- **Framework:** Flutter (Dart)
- **State Management:** Native `setState` (for simplicity and learning)
- **Networking:** `http` package for REST API calls
- **Backend/Mock API:** [crudcrud.com](https://crudcrud.com) (A free mock REST API service)
